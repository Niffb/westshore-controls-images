# Westshore Controls Images Repository

This repository contains all images for the Westshore Controls website, served via GitHub CDN for improved performance.

## Structure
- `brands/` - Brand logos and related images
- `categories/` - Product category images
- `products/` - Product-specific images organized by brand
- `mccb/` - NOARK MCCB product images
- `tmeic/` - TMEIC product images

## Usage
Images are served via GitHub raw URLs:
`https://raw.githubusercontent.com/Niffb/westshore-controls-images/main/[path-to-image]`
